# Danish M — AI & Data Science Engineering Portfolio

An interactive, high-performance personal portfolio built with React, Vite, Tailwind CSS, and custom shader/canvas interaction systems. Art-directed with a dark Cyber-Samurai aesthetic, fluid responsive layout, and zero third-party UI framework bloat.

![Portfolio Banner](public/port-image-removebg-preview.png)

---

## ⚡ Core Highlights

- **Custom Cyber-Samurai Preloader**: 0% to 100% telemetry counter with dynamic engineering status diagnostics, tactical HUD brackets, crimson laser sweep, and an instant skip shortcut.
- **Strict Viewport Architecture**: Fluid `100dvh` responsive scaling across Ultra-Wide, Desktop, Tablet, and Mobile displays.
- **Dual Performance Mastery Matrix**: Interactive stance switcher (`Algorithmic Rigor` & `Production Systems`) optimized for touch screens and desktop displays alike.
- **Zero Third-Party UI Kits**: Tailored bespoke components engineered directly with Tailwind CSS, Lucide icons, and modern React hooks.
- **Instant Section Anchoring**: Automated browser scroll restoration management ensuring consistent hero landings.

---

## 🛠️ Technology Stack

- **Framework**: [React 18](https://react.dev/)
- **Build Tool**: [Vite 5](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 3](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations / Visuals**: CSS Transforms, Canvas 2D Embers, HTML5 Canvas

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18 or newer recommended) installed.

### Installation

```bash
git clone https://github.com/danish-2323/portfolio.git
cd portfolio
npm install
```

### Development Server

Start the local development server with Hot Module Replacement (HMR):

```bash
npm run dev
```

### Production Build

Compile the optimized production bundle:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
